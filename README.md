# Helpdesk Support Dashboard

A beginner-friendly React + Vite helpdesk support dashboard.

## Included

- Dashboard analytics
- Ticket listing
- Create ticket
- Edit ticket
- Ticket details
- Assign ticket
- Priority/status/category
- Comments
- Activity timeline
- Attachment UI
- SLA indicators
- Search, filters and sorting
- Pagination
- Charts
- Form validation
- Confirmation modal
- Loading, error and empty states
- Toast notifications
- Responsive layout
- Reusable components
- Micro animations
- LocalStorage persistence
- No backend required

## Run

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.

## Structure

```text
src/
  components/
  data/
  layouts/
  pages/
  App.jsx
  main.jsx
  styles.css
```

This project intentionally keeps the code simple so it is easy to understand and extend.
